# Спецификация: чистая основа ролика (с 2026-10-02)

- На каждый ролик Cursor делает ОДНУ чистую основу; боты площадок (YouTube — Рилсы, VK — ВК Аплоадер, Дзен — Дзен Аплоадер) дорабатывают её сами (надписи, подписи, хештеги, время выкладки).
- Видео: 1080×1920, 9:16, без чёрных рамок; при горизонтальном исходнике спортсмены всегда в центре (reframe/pan-follow, без статичного center-crop); суть в первые 1–3 с, без заставки и логотипа в начале; финал полный, не обрезанный.
- Без надписей поверх видео: без WOW-бренда, имён, CTA, NEXT, Telegram, водяных знаков других площадок.
- Два звуковых варианта отдельными файлами: `<slug>_orig.mp4` (оригинальный звук) и `<slug>_nomusic.mp4` (без музыки: шум зала или тишина) — фонограмма программы чужая, риск блокировки.
- Файл фактов `<slug>_facts.json`, только проверенные: athletes (RU + латиница), tournament, city, country, date, discipline, exercise (balance/dynamic/combined), score, place; неизвестное = null, ничего не выдумывать.
- Готовые файлы — в outbox / артефакты, сообщить пути.

## Что устарело

Для новых заданий эту спецификацию заменяют собой WOW-брендинг и вшитый оверлей (жёлтая полоса, хук WOW, имена и город, CTA), саундтрек только из музыки Kie и приглушённый звук зала.

Код остаётся для старых заданий: `pipeline/assemble.py`, `pipeline/music_kie.py`, `pipeline/textutil.py`.
