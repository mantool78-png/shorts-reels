# Спецификация: чистая основа ролика (с 2026-10-02)

- На каждый ролик Cursor делает ОДНУ чистую основу; боты площадок (YouTube — Рилсы, VK — ВК Аплоадер, Дзен — Дзен Аплоадер) дорабатывают её сами (надписи, подписи, хештеги, время выкладки). Свою музыку боты не генерируют.
- Видео: 1080×1920, 9:16, без чёрных рамок; при горизонтальном исходнике спортсмены всегда в центре (reframe/pan-follow, без статичного center-crop); суть в первые 1–3 с, без заставки и логотипа в начале; финал полный, не обрезанный.
- Без надписей поверх видео: без WOW-бренда, имён, CTA, NEXT, Telegram, водяных знаков других площадок.
- Три звуковых варианта отдельными файлами: `<slug>_orig.mp4` (оригинальный звук), `<slug>_nomusic.mp4` (без музыки: шум зала или тишина) и `<slug>_kie.mp4` (оригинальный звук убран, один новый трек Kie — основной файл для публикации на YouTube, VK и Дзен). Трек Kie Cursor генерирует ОДИН раз на ролик. Фонограмма программы чужая, риск блокировки.
- Файл фактов `<slug>_facts.json`, только проверенные: athletes (RU + латиница), tournament, city, country, date, discipline, exercise (balance/dynamic/combined), score, place; неизвестное = null, ничего не выдумывать.
- Готовые файлы — в outbox / артефакты, сообщить пути.

## Что устарело

Для новых заданий устарели WOW-брендинг и вшитый оверлей (жёлтая полоса, хук WOW, имена и город, CTA). Код оверлея остаётся для старых заданий: `pipeline/assemble.py`, `pipeline/textutil.py`.

Шаг музыки Kie снова действует. `pipeline/music_kie.py` и `--music` используются для `<slug>_kie.mp4`: оригинальный звук убран, один новый трек на ролик. Рядом по-прежнему лежат `<slug>_orig.mp4` и `<slug>_nomusic.mp4`.
