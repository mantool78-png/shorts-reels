# QA перед показом человеку

> ⚠️ С 2026-10-02 для новых роликов действует docs/CLEAN_BASE_SPEC.md

Готовый файл: вертикаль 9:16, примерно 30–50 сек, имя вида `WOW_..._YYYYMMDD_HHMMSS.mp4` в `outbox/`.

## Картинка

- [ ] Сверху жёлтая полоса `#FFD60A`
- [ ] Хук WOW крупный (Impact ~118), первые ~2.6 с
- [ ] Имена и город одним кеглем (~52), имена заглавными
- [ ] На плашке город из `--city`, не канал
- [ ] Канал «Слово Акробата» на кадрах **нет**
- [ ] Четвёрка: две строки `Фамилия · Фамилия`, без `&`
- [ ] В конце CTA ~46, без слова «подписка»/«подпишись», без `:` (двоеточие ffmpeg режет)

## Нарезка

- [ ] Первый кусок — хук (для tempo/combined — выброс/сальто)
- [ ] Последний кусок — фиксация 2–3 с (поза / салют судьям), не статика перед прыжком и не полёт
- [ ] `--style` совпадает с упражнением (не путать баланс и темп)
- [ ] Balance: если не золото Айсиной — можно 2–3 с дорожки шагов между элементами
- [ ] Золото Айсиной: без dance connectors
- [ ] Ручные клипы совпадают с тем, что сказал тренер (после перевода `1.02` → `1:02`)

## Звук и мета

- [ ] Зал вырезан (mute на кусках); музыка инструментал или явно `--skip-music`
- [ ] `.meta.json` рядом с mp4: есть `youtube_title` и `subscribe_line`
- [ ] `subscribe_line` из колоды weekly (`config.yaml` `subscribe_why`), не «подпишись»
